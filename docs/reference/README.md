# Reference material

Crops and glyphs used to **measure** Fortnite's HUD, and nothing else. None of this ships
in the jar.

- Every file's origin is recorded in [../ASSETS.md](../ASSETS.md), under *Reference
  material (not shipped)*.
- The numbers derived from them live in [../FIDELITY.md](../FIDELITY.md), in *The health
  and shield meter, Chapter 7* and *The ping feed, and where it sits*.
- These are measurements of Fortnite, not art this mod uses. Wiki content is CC BY-NC-SA
  3.0 and the underlying art is Epic's, so they are for private measurement only.

If you replace a file here, update the numbers it fed. A stale measurement with a fresh
image is worse than either alone.
